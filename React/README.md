# React + TypeScript + Vite + DevExtreme

To integrate the chart popup in your React application, follow these steps:

1. Copy `src/components/chart`, `src/hooks`, and `src/utils` into your application. Import the `useGridData` hook in the component where you initialize your dxDataGrid instance and define the following properties:

    ```ts
    import { useGridData } from '../hooks/useGridData';

    export default function Home(): JSX.Element {
        const {
            gridRef,
            gridDataSource,
            chartData,
            chartPopupVisible,
            isDataGridEmpty,
            hasSelectedRows,
            onlySelected,
            showChartPopup,
            handleRowClick,
            handleSelectionChanged,
            handleContextMenuPreparing,
            handleVisibleChange,
            handleOnlySelectedChange,
        } = useGridData();
    }
    ```

2. Update types and variables in `src/utils/chart-data.ts` to match field names in your data set. Replace all instances of `GridDataItem` with your grid data type (this example imports `GridDataItem` from `src/data/grid-data.ts`).

3. Import and add the `<ChartPopup>` component beside your dxDataGrid instance. Assign properties generated by the `useGridData` hook to the component:

    ```jsx
    export default function Home(): JSX.Element {
        return (
            <>
                <DataGrid />
                <ChartPopup
                    visible={chartPopupVisible}
                    chartData={chartData}
                    onlySelected={onlySelected}
                    hasSelectedRows={hasSelectedRows}
                    onVisibleChange={handleVisibleChange}
                    onOnlySelectedChange={handleOnlySelectedChange}
                />
            </>
        )
    }
    ```

4. Call `showChartPopup()` (generated by `useGridData`) to invoke the chart popup. This example calls `showChartPopup()` in the click handler of a toolbar button. `useGridData` also calls `showChartPopup()` in the hook's built-in `handleContextMenuPreparing` function (assigned to dxDataGrid's `onContextMenuPreparing`).

    ```jsx
    const renderChartButton = useCallback(() => (
        <Button
            onClick={showChartPopup}
        />
    ), [ /* ... */ ]);

    export default function Home(): JSX.Element {
        return (
            <>
                <DataGrid
                    onContextMenuPreparing={handleContextMenuPreparing}
                >
                    <Toolbar visible={true}>
                        <ToolbarItem location="after" render={renderChartButton} />
                    </Toolbar>
                </DataGrid>
            </>
        )
    }
    ```

For additional information about this example, refer to the [main readme](../README.md).

## Build and Run

Prerequisites: Node.js.

Install dependencies:
```sh
npm install
```

Start dev server:
```sh
npm run dev
```
Open: http://localhost:5173/

Build production bundle:
```sh
npm run build
```

Run linter:
```sh
npm run lint
```
